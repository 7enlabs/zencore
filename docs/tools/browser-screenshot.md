# browser_screenshot

Capture a screenshot of the current page as a PNG image.

## Parameters

- `selector` (string, optional): CSS selector of one element. Omit for the viewport.
- `full_page` (boolean, optional): Capture the whole page, default false.

## Behavior

- Returns the screenshot as a PNG image.
- Read-only tool: runs without approval in `default` mode.

## Phase bundle

`read` (exploration).
