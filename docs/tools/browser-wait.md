# browser_wait

Wait until an element appears or a text appears in the page.

## Parameters

- `selector` (string, optional): Wait for this element to appear.
- `text` (string, optional): Wait for this text to appear in the page text.

## Behavior

- Waits for the element or text to appear, up to the tool timeout.
- Read-only tool: runs without approval in `default` mode.

## Phase bundle

`read` (exploration).
